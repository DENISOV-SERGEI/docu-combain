# Локальные данные

Поместите сюда собственный файл `students.xlsx`, если хотите использовать его
как таблицу по умолчанию. Таблицы Excel игнорируются Git, поскольку могут
содержать персональные данные.

Обязательные заголовки: `student_name`, `course_name`, `score`, `issue_date`.
Необязательные заголовки: `signature_path`, `stamp_path`.
